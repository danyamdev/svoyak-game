# Дизайн-система

## Концепция

Рабочая утверждённая концепция — яркая «Хэллоуин-вечеринка»: игровое шоу с
контрастными карточками, дружелюбными эмодзи и без тяжёлой хоррор-эстетики.

## Токены

Источник истины — `src/app/styles/global.scss`.

| Назначение       | Значение             |
| ---------------- | -------------------- |

| Фиолетовый       | `#6c34c9`            |
| Оранжевый акцент | `#ff7a00`, `#ffad33` |

Display-шрифт: системный rounded fallback. Основной: Inter при наличии, затем
системные sans-serif.

## UI-принципы

- Светлые ячейки вопросов на тёмном фоне; использованные вопросы визуально гаснут.
- Оранжевый — основное действие, лаймовый — статус/заголовок, cyan — focus ring.
- Модальные сценарии строятся на Radix UI и не закрываются случайным кликом во
  время вопроса.
- Интерактивные элементы обязаны иметь `:focus-visible`, disabled-состояние и
  текстовую метку.
- Повторяющиеся диалоги и валидируемые поля размещаются в `shared/ui`.

## Адаптивность и движение

- Минимальная ширина документа — 320 px.
- Поле и scoreboard упрощаются на брейкпоинтах 768 px и 480 px.
- Анимации декоративны и должны отключаться через `prefers-reduced-motion`.
- Новые экраны проверяются минимум на телефоне, планшете и широком desktop.
