# Roadmap

Каждый пункт рассчитан на отдельную рабочую сессию. Порядок меняется только после
обновления зависимостей и приоритетов.

## Завершено

1. **Основа проекта:** React/Vite, линтеры, SCSS Modules, маршруты.
2. **Сессия:** участники и команды, `localStorage`, восстановление страницы.
3. **Основная игра:** поле 5×5, ответы, очки, rebound, пропуск, undo.
4. **Раунды и спецвопросы:** три раунда, кот, аукцион.
5. **Финал:** темы, ставки, судейство, tie-breaker, результаты.
6. **Пакет игры:** редактор, JSON import/export, 75 стартовых вопросов.
7. **Инструменты ведущего:** ручная коррекция и защитные подтверждения.
8. **Валидация редактора:** обязательные поля и альтернативные ответы.
9. **Устойчивость сессии:** проверка восстановления всех игровых фаз.
10. **E2E smoke-тест:** полный путь от setup через 75 вопросов до результатов.
11. **Accessibility и responsive-аудит:** клавиатура, focus trap и ширины 320/768/1440 px.

## Ближайшие задачи

### 1. Настроить CI

- **Цель:** автоматически проверять unit-тесты, сборку и критический E2E-сценарий.
- **Модули:** GitHub Actions и тестовые команды.
- **Результат:** pull request получает воспроизводимый статус проверок.
- **Готово:** workflow проходит в чистом окружении с кэшированием Yarn/Playwright.

## После решения продуктовых вопросов

- Таймеры и/или баззер.
- Media content blocks в редакторе и экране вопроса.
- Настраиваемые размер поля и число раундов.
- PWA/offline-режим.
- CI, хостинг и release checklist.
