# Roadmap

Каждый пункт рассчитан на отдельную рабочую сессию. Порядок меняется только после
обновления зависимостей и приоритетов.

## Завершено

1. **Основа проекта:** React/Vite, линтеры, SCSS Modules, маршруты.
2. **Сессия:** участники и команды, `localStorage`, восстановление страницы.
3. **Основная игра:** поле 5×5, ответы, очки, rebound, пропуск, undo.
4. **Раунды и спецвопросы:** три раунда, кот, аукцион.
5. **Финал:** темы, ставки, судейство, tie-breaker, результаты.
6. **Пакет игры:** редактор, JSON import/export, 75 стартовых вопросов.
7. **Инструменты ведущего:** ручная коррекция и защитные подтверждения.

## Ближайшие задачи

### 1. Завершить валидацию редактора

- **Цель:** исключить пустые обязательные поля и редактировать альтернативные ответы.
- **Модули:** editor page, definition store, shared fields.
- **Результат:** понятные inline-ошибки и нормализованные варианты ответов.
- **Готово:** unit-тесты, ручная проверка persistence, `yarn validate`.

### 2. Проверить устойчивость сессии

- **Цель:** гарантировать восстановление каждой игровой фазы после reload.
- **Модули:** persisted state, session store, game engine.
- **Результат:** тестовая матрица фаз и безопасный fallback повреждённых данных.
- **Готово:** тесты миграций и восстановления проходят без изменения правил.

### 3. Добавить сквозной smoke-тест

- **Цель:** автоматически пройти setup → вопрос → следующий раунд → финал.
- **Модули:** тестовая инфраструктура и ключевые страницы.
- **Результат:** один стабильный критический сценарий.
- **Готово:** инструмент и новая зависимость предварительно согласованы; тест работает в CI.

### 4. Довести UX и accessibility

- **Цель:** проверить клавиатуру, focus management и мобильные размеры.
- **Модули:** pages, widgets, shared UI.
- **Результат:** ведущий проводит игру без мыши и без обрезанного контента.
- **Готово:** ручной checklist и исправления критических проблем.

## После решения продуктовых вопросов

- Таймеры и/или баззер.
- Media content blocks в редакторе и экране вопроса.
- Настраиваемые размер поля и число раундов.
- PWA/offline-режим.
- CI, хостинг и release checklist.
